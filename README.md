# Low Birth Rate Analysis Dashboard

This Tableau project explores the global impact of low birth rates, highlighting current trends, technological responses, and public policy strategies across major nations.

## 🔍 Project Overview
- **Objective:** Analyze global birth rates and the strategies countries use to mitigate aging populations.
- **Key Topics Covered:**
  - Global birth rate comparison
  - Technology use for aging populations
  - Policy responses like immigration and family support
  - Storytelling through Tableau Story feature

## 📊 Visuals Included
- Scatter plot: Birth rate vs. % population over 65
- Table: Tech use & policy support per country
- Story dashboard summarizing findings

## 📁 Files
- `birth rates vs country populations.twbx`: Tableau workbook
- `country population birthrates.xlsx`: Raw data used for analysis

## 🌐 Live Tableau Public Viz
[View the full dashboard here](https://public.tableau.com/app/profile/benjamin.kovacevich/vizzes)

## 🧠 Key Insights
- Countries with low birth rates often have high aging populations
- Investment in tech and immigration is crucial for long-term sustainability
